# Wolverine to DS5 使用说明

适用版本 1.1.46 及以上

Wolverine to DS5 把雷蛇幻影战狼 V3 Pro 手柄变成一只虚拟的 PS5 DualSense 手柄，让 PC 游戏把这只手柄当成 PS5 手柄使用，并把游戏里的震动送到左右握把。

装好后，游戏里会多出一只 DualSense；实体手柄默认被 HidHide 隐藏，别的程序只看到虚拟手柄；握把震动由雷云（Razer Synapse）驱动。雷云要装完整；握把震动用它自带的触觉组件，不需要单独安装。

开始前先准备：Windows 10/11 64 位；一只幻影战狼 V3 Pro，用 USB 线或 2.4G 接收器连接，模式拨到 PC；雷云已安装、已登录并保持联网。USBIP 和 HidHide 由安装包检测并引导安装，不用提前准备。

程序只支持 PC 模式：手柄在 Xbox 模式时，状态页会提示「请切换到 PC 模式」，拨回 PC 后会自动连接。

## 安装

1. 从 GitHub Releases 下载最新的 `Wolverine-DS5-Setup-<版本>.exe`。
2. 双击安装。安装包自带运行环境，不需要装 Python；默认装到 `%LOCALAPPDATA%\Programs\Wolverine DS5`，并创建开始菜单快捷方式。桌面快捷方式可以在安装向导里勾选。
3. 装完会自动跑一次隐藏自检，并检查 USBIP、HidHide 和雷云。
4. 如果提示缺 USBIP 或 HidHide，或者 USBIP 版本过旧、驱动不完整，选「是」让安装向导自动安装。会弹一次 UAC，安装过程需要联网；自动安装使用官方 USBIP 0.9.8.0 和 HidHide 1.5.230。
5. 如果 UAC 被取消或自动安装失败，按提示的地址手动安装，然后重新运行安装包再检测一次。
6. 如果没有雷云，安装包只会打开雷云下载页。雷云需要登录账号安装，无法静默完成；装好后登录，保持联网和运行。
7. 如果安装向导补装了 USBIP 或 HidHide，完成页会要求重启。第一次安装通常属于这种情况，请重启电脑；驱动要重启后才生效。自检通过的话，重启后程序会自动打开，并在第一次自检后提示结果；没有自动打开就从桌面或开始菜单启动。
8. 覆盖安装时不用手动关雷云：安装器只会请本程序自己退出，雷云可以一直开着。
9. 如果当时跳过了依赖安装，之后重新运行同一个安装包会再次检测。

安装包不会自动更新。状态页出现「发现新版」时，点它打开发布页，下载新安装包，再按上面的步骤覆盖安装。

安装时如果旧版本还在运行，安装程序会先让它退出；提示「Wolverine DS5 还在运行」时，右键任务栏右下角的程序图标选「退出」，再回到安装向导点「下一步」。

## 第一次使用

1. 先关掉会抢手柄的软件：飞智空间站、DS4Windows、ViGEm 客户端等。它们也会挂虚拟手柄，游戏会看到多只手柄。
2. 把手柄的模式开关拨到 PC 模式，用 USB 线或 2.4G 接收器连电脑。只保留一只幻影战狼 V3 Pro；同时插线和接收器会让程序无法选择。
3. 从桌面或开始菜单启动 Wolverine DS5。
4. 看状态页：等「虚拟 DualSense」显示「已挂载」，顶部显示「已连接」。刚启动时握把可能要等 10–20 秒；这期间「震动测试」显示「等待雷云…」是正常的。
5. 再启动游戏。顺序是程序在前、游戏在后。中途重启了程序，就要退出游戏重新进。
6. 如果状态页显示「等待握把震动服务」或「雷云未运行，握把不可用」，按键仍然可用；点「启动雷云」或按自检提示处理。
7. 如果游戏里同时看到两只手柄，或看到的是 Xbox 手柄：到「系统」页把「对游戏隐藏实体手柄」关一下再打开；已经开着的游戏和 Steam 要完全退出后重开。

记住三句话：程序在前、游戏在后；程序重开过，游戏也要重开；握把不震先看雷云。

窗口右上角的 × 只是收进托盘，程序继续运行。要真正退出，用托盘菜单的「退出」。

## 界面怎么看

### 状态页

- 顶部可以在「状态」「系统」两页之间切换；右上角显示「已连接 · MM:SS」或「未连接」，以及当前模式（如「PC 模式」）。
- 大标题和说明显示当前状态；下面的按钮可能是「启动桥接」「停止桥接」或「请切换到 PC 模式」。
- 中间一行有四项：
  - 「虚拟 DualSense」：显示「已挂载」「未挂载」或「检查中」。显示「未挂载」时游戏看不到虚拟手柄，先看桥接和 USBIP。
  - 「雷蛇 Sensa」：显示「就绪」「等待」「雷云离线」或「未检测」。显示「等待」时按键正常、握把还没就绪；显示「雷云离线」时先恢复网络。
  - 「游戏触觉」：显示「未启动」「还没收到」「已收到（最近 N 秒）」或「最近 30 秒没收到」。游戏里有触觉效果却一直「还没收到」，说明触觉没发到虚拟手柄，先查游戏内震动和 Steam Input。
  - 「HidHide」：显示「开启」「关闭」「未生效」或「失败」。显示「未生效」时游戏可能看到两只手柄，到系统页把开关关一下再开。
- 「握把震动」卡片：握把总开关、强度、触觉配置文件、打击加重和震动测试。
- 「实时输出（估算）」：左右握把的电平条。
- 底部是自检摘要、版本号和模式；有新版本时会显示「发现新版 x.y.z」，点它打开发布页。程序不会自动更新。

### 系统页

- 「系统」卡片：开机自启、默认音频自动切回、对游戏隐藏实体手柄，以及日志的「打开目录」「导出日志」。
- 「自检」卡片：列出各项检查和「重新检查」。状态有「正常」「提醒」「未通过」「跳过」。
- 自检摘要如果是「按键可用，握把未就绪：……」，说明手柄和按键正常，只是握把链路没通；按状态页上提示的按钮逐项处理。

### 托盘

右键任务栏的程序图标，可以「打开主界面」「停止桥接」或「启动桥接」「启动雷云」「退出」。

## 触摸板

实体手柄没有触摸板，虚拟 DualSense 有：

- 按住 View（双方块键），推右摇杆：手指在触摸板上滑动。摇杆居中对应触摸板中心，推到底对应边缘。
- 轻点 View：触摸板点击。

不是每个游戏都使用触摸板；游戏不支持时没反应是正常的。

## 握把震动怎么调

- 「握把震动」总开关：关掉后，强度、震动测试和实时输出一起失效。
- 「握把强度」：0–150%，左右握把同时生效，0% 等于关闭。默认是 100%；不确定就调到 100%。
- 「触觉配置文件」：默认「打击」。可以试「旧版」「受控」「平衡」「平衡+」「动态」「打击」，选自己觉得舒服的。
- 「打击加重」：默认关闭。打开后打击瞬间会更重；觉得太猛就关掉，回到加重前的手感。
- 「震动测试」：点「按住 LT / RT 测试」，然后按住 LT 或 RT。按钮变成「结束测试」时，再点一次可以停止；显示「等待雷云…」说明雷云还没识别握把。
- 「全链路测试」：先左握把、再右握把各 1.5 秒。它不经过游戏，能区分是游戏没发触觉，还是握把链路有问题；只震一边或都没震，到系统页导出日志。
- 「实时输出（估算）」：两条电平条会跟着游戏震动变化，用来判断有没有信号。游戏震动时电平条不动，先查游戏是否把触觉发给了虚拟手柄。
- PC 模式只驱动左右握把，扳机不会震；这是当前设计的限制。
- 握把强度和雷云里这只手柄的震动强度是相乘关系；任意一边是 0，握把都不会震。
- 这些设置改完立即生效，不用重启游戏或桥接。

## 有线 / 2.4G 怎么切

- USB 线和 2.4G 接收器都支持，程序会自动识别，不用改设置。
- 运行中换连接：拔线、插接收器，或者反过来。程序会自动重连，虚拟 DualSense 会一直保留，游戏通常不用因为换连接而重开；一般 1–2 秒恢复。没有恢复就点「重启桥接」。
- 换到新的 USB 口或接收器后，HidHide 会把它当成新实例。如果游戏又能看到实体手柄，到「系统」页把「对游戏隐藏实体手柄」关一下再打开；隐藏生效后要重开游戏。
- 想最稳就用 USB 线；2.4G 也能正常玩。
- 不要同时插线和接收器，否则程序无法选择用哪一只。

换完连接先等 1–2 秒；没有恢复就点「重启桥接」；仍然不行再退出游戏重进。

## 使用限制

- 只支持 PC 模式。手柄在 Xbox 模式时程序不接管，只提示切换。
- PC 模式只驱动左右握把，扳机不会震。
- 雷云必须运行、已登录并联网；离线时按键可用，握把不可用。
- 程序要先于游戏启动；程序重启后，游戏也要重开。
- HidHide 按设备实例隐藏；换 USB 口或接收器后，要重新隐藏一次。
- 雷云的「音频转震动」实测不影响握把，不用特意关；只有遇到无端震动时再排查。
- 2.4G 接收器可用；想最稳就用 USB 线。

## 常见问题

先看状态页和系统页的自检。自检摘要写「按键可用，握把未就绪」时，手柄和按键是正常的，只是震动链路没通。

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 游戏里看不到手柄，或同时看到两只 | 游戏比程序先开；实体手柄没隐藏；飞智空间站、DS4Windows、ViGEm 也在挂虚拟手柄 | 先开程序再开游戏；系统页把「对游戏隐藏实体手柄」关一下再开；完全退出游戏和 Steam 后重开；关掉上述软件 |
| 状态页一直「等待手柄」，或「虚拟 DualSense」是「未挂载」 | 手柄不在 PC 模式；桥接没起来；USBIP 没装好 | 把手柄拨到 PC 模式；点「重启桥接」；按自检提示装 USBIP，装完重启 |
| 握把完全不震 | 雷云没运行、没登录或离线；刚启动还在等；握把开关关或强度为 0；游戏先开 | 点「启动雷云」；等「雷蛇 Sensa」变「就绪」（10–20 秒）；打开「握把震动」、强度调到 100；退出游戏重进 |
| 软件内「震动测试」没反应 | 按钮显示「等待雷云…」；雷云里这只手柄的震动强度是 0 | 等雷云识别握把，或点「启动雷云」；把雷云里的震动强度调高；仍不行导出日志 |
| 雷云离线或没登录 | 雷云启动时没联网，进入离线模式，不加载手柄；或账号没登录 | 恢复网络，点「启动雷云」重开；确认已登录、手柄在雷云里可见 |
| 杀软报毒或拦截，或装完启动不了 | 文件被隔离或删除，安装被中断 | 把安装目录加入白名单；重新运行安装包修复；启动日志看 `%LOCALAPPDATA%\WolverineDS5\logs\startup-crash.log`，安装自检看 `%TEMP%\WolverineDS5-self-test.log` |
| 安装时提示文件被占用或需要重试 | 旧版程序还在运行 | 右键任务栏右下角的图标选「退出」，再回到安装向导点「下一步」 |
| 自检说「USBip 驱动不完整」或「USBip 驱动被删除」 | 缺少 `usbip2_ude` 或 `usbip2_filter`；或驱动被安全软件删了 | 点「安装 USBip」打开官方页装 0.9.8.0，或重跑本程序安装包自动补装；重启；不要手动删 USBIP 驱动或服务 |
| 装过飞智 X-Haptics（XDS），能一起用吗 | 两者共用官方 USBIP 0.9.8.0，驱动不冲突；但都会挂虚拟手柄 | 可以都装；不要同时运行，玩本程序时退出飞智空间站；反过来也一样 |
| 卸载后想还原，或手柄仍被隐藏 | 卸载时取消了 UAC，收尾没做 | 重新运行安装包再卸载并允许 UAC；或到 HidHide 客户端取消隐藏、在任务计划程序删除 `WolverineDS5-RazerSynapse` |
| 不想开机自启 | 系统页「开机自启」开着 | 到系统页关掉；卸载也会删除自启项 |
| 换 USB 口或接收器后，游戏又能看到实体手柄 | HidHide 按设备实例隐藏，新接口没登记 | 系统页把「对游戏隐藏实体手柄」关一下再打开；隐藏后重开游戏 |
| 自检说「雷云版本不受支持」 | 雷云更新后编码器接口变了 | 点「反馈问题」把版本信息发给作者；更新本程序后恢复。按键仍可用 |
| 握把偏弱或太强 | 握把强度、雷云震动强度、游戏触觉强度叠加 | 调「握把强度」；确认雷云里不是 0；换「触觉配置文件」试 |
| 关掉窗口后程序不见了 | 右上角 × 只是收进托盘，程序没有退出 | 在任务栏右下角的托盘区找程序图标，双击打开；找不到就从开始菜单再启动，已有实例会把窗口叫出来 |
| 状态页显示「请切换到 PC 模式」 | 手柄在 Xbox 模式 | 把手柄模式开关拨回 PC，程序会自动连接，不用重启程序 |
| 游戏有触觉，握把不动或只有一边 | 游戏没把触觉发给虚拟手柄；Steam Input 接管；握把链路有问题 | 先做「全链路测试」；再查游戏内震动开关和 Steam Input；只震一边就导出日志 |

## 卸载

1. 先退出游戏，再退出程序：右键托盘图标，选「退出」。程序会卸掉虚拟 DualSense、恢复实体手柄；恢复失败会提示，按提示重试，不要直接强杀进程。
2. 从开始菜单打开「卸载 Wolverine DS5」；也可以在 Windows 的「设置 → 应用」里找到它卸载（Windows 10 叫「应用和功能」）。
3. 卸载开始时可能弹一次 UAC，选「是」。收尾需要管理员权限。
4. 卸载会：移除虚拟手柄；解除 HidHide 对实体手柄的隐藏；删除计划任务 `WolverineDS5-RazerSynapse`；取消开机自启；删除程序文件。
5. 卸载不会：删除 USBIP 或 HidHide 驱动和服务。它们可能还被飞智 X-Haptics 等工具使用；不要手动删除 USBIP 驱动或服务，删了可能破坏 USB 层，严重时要重装系统。
6. 如果取消了 UAC：程序文件会删掉，但收尾没做；实体手柄可能仍被隐藏、虚拟手柄仍挂载、计划任务仍在。重新运行安装包再卸载一次并允许 UAC；或到 HidHide 客户端取消隐藏、在任务计划程序删除 `WolverineDS5-RazerSynapse`。
7. 卸载不会动雷云配置。日志在 `%LOCALAPPDATA%\WolverineDS5\logs`，设置文件在 `%APPDATA%\WolverineDS5\settings.json`，不会随卸载删除。

正常卸载后，实体手柄会恢复可见，不用额外设置；如果游戏仍看不到，先完全退出游戏和 Steam 再开。

## 给开发者反馈

1. 先导出日志：打开「系统」页，找到「日志」，点「导出日志」，选择保存位置（默认桌面）。会得到一个 `WolverineDS5-diagnostics-日期-时间.txt` 文件，把它一起发。导出的文件包含设置、桥接状态、自检结果和最近日志，不用手动挑选。
2. 记下版本号：状态页右下角显示 `Wolverine to DS5 · 版本 · 模式`，导出的日志里也有。
3. 说明这些信息：游戏名和场景；现象（完全没震、偏弱、偏强、左右不一致、触摸板没反应等）；用的是线还是接收器；握把强度；雷云是否登录并联网；是不是先开程序后开游戏。
4. 反馈前先点一次「重新检查」，让自检结果是最新的。自检里出现「反馈问题」按钮时，点它会打开一个已经带好版本、系统信息和自检结果的 GitHub Issue；补充现象后提交。
5. 安装或启动失败：附上 `%TEMP%\WolverineDS5-self-test.log`（安装自检）或 `%LOCALAPPDATA%\WolverineDS5\logs\startup-crash.log`（启动失败）。
6. 日志目录：`%LOCALAPPDATA%\WolverineDS5\logs`；设置文件：`%APPDATA%\WolverineDS5\settings.json`。
