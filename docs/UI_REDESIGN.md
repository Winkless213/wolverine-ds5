# Wolverine DS5 UI 重设计说明（草案）

来源：Qoder 项目记忆 `wolverine-ds5-ui-direction.md`（2026-10-24）与 2026-10-25 用户补充。
路线：PC 模式为唯一产品路线；Xbox 模式与扳机链路保留在代码里作实验性实现，但不出现在界面。

## 1. 视觉方向

- v3（2026-10-25）：用户明确要求照雷云 4（Razer Synapse）的 UI 和色调重做；v2 的玻璃/石墨/粒子方向废弃。
- 关键词：雷云式深灰平面、绿色标题与控件、点阵背景、产品手柄大图 + 绿色标注、信息密度高、直接，不做“艺术化”氛围。
- 顶栏 `#181818`、Tab 条 `#1B1B1B`、页面 `#1F1F1F`、卡片 `#161616`（比页面更黑，形成雷云式黑色显示框）、描边 `#3A3A3A`；点阵 `#3A3A3A`、18px 间距。
- 主色雷蛇绿 `#44D62C`：用于激活 Tab 胶囊、卡片标题、开关、滑杆、手柄标注；不做整屏光晕或绿色底雾。大面积电平柱改用暗一档的 `#35A827`，避免整块高亮刺眼。
- 文字 `#F2F2F2`，次级 `#C8C8C8`，弱化 `#9C9C9C`；警告 `#E8B454`；错误 `#F06A6A`。
- 字体：拉丁与数字用随包 `Roboto`（Regular/Medium/Bold）；中文不能用 Roboto（它没有汉字字形），必须显式回退到微软雅黑，否则 Qt 会掉到宋体，字细且带衬线。QML 的 font 值类型没有 `families` 属性，逐项写 `font.family` 会把回退链覆盖成单一字体，因此回退链统一设在 `app/qml_window.py` 的 `FONT_STACK`（`Roboto → Microsoft YaHei UI → Microsoft YaHei → Segoe UI`）作为应用默认字体，QML 里不再写 `font.family`。中文标题 16–18px、正文/状态 14–15px，字重统一 600（雅黑只有 Regular/Bold，500 会退回 Regular 变细）。白色正文 `#D8D8D8` / 强调 `#E8E8E8`。Roboto 为 Apache-2.0。
- 控件：4px 圆角、1px 描边、平面卡片；不用毛玻璃、大面积渐变、霓虹描边。
- 图标：自绘线性 SVG；激活态雷蛇绿。

## 2. 布局与页面

窗口基准 1180 × 780，最小 980 × 760。

- 顶部标题栏 + 下方 Tab：状态 / 系统（两个页面，不再单列震动页）；激活项为绿色胶囊，深色文字。
- 右上固定：连接状态点 + “已连接”、PC 模式胶囊。
- 状态页：手柄产品图 + 一行只读状态（DualSense / Sensa / 音频保护 / HidHide）+ 握把震动卡片（总开关 / 左握把强度 / 右握把强度 / 柔和 / 测试按钮）+ 实时输出柱状图；输出与测试都只在这一页出现，避免重复。手柄图上的左右标注实时显示百分比，点击选中并高亮对应强度行；总开关关闭时标注、两条强度、柔和与测试一起禁用。
- 系统页：开机自启、音频保护、HidHide、日志（打开目录 / 导出诊断 txt）；不出现关于卡片、减少动画开关与 Xbox 驱动切换。
- 页面切换：只替换内容区，不重建窗口；预加载页面，避免首次切换卡顿。

## 3. 动效

- 雷云式克制：Tab 切换 140–180ms 淡入/淡出，不做大幅位移或缩放。
- 电平/滑杆使用 200ms 线性缓动，禁止逐帧跳变；开关 120ms。
- 不弹跳、不闪烁、不突然改变布局；状态变化用颜色/透明度过渡。
- 悬停不做绿色底色/描边动画；可点击元素只保留指针形状，避免卡片整块变绿。
- 页面过渡保留 `reduce_motion` 设置（默认关闭），但系统页不再暴露开关。

## 4. 背景

- 静态点阵背景 + 卡片/手柄阴影；不再使用粒子、飘带或 Canvas 动画。
- 窗口隐藏/最小化时停止电平刷新；游戏运行期间后台不产生动画开销。
- 状态页手柄使用 Razer 官网 Wolverine V3 Pro 产品渲染（透明底，已裁切，mockup 阶段使用）；发布安装包前需确认素材授权，或替换为自有渲染/实拍图。

## 5. QML 技术路线

- PySide6 6.12 已带 QtQuick/QtQml；用 QML 重写状态页与震动页，Python 通过 `QObject` 上下文暴露状态、设置和动作。
- 不使用 QWidget 换肤，也不使用 QQuickWidget 半新半旧混搭；新窗口为 QML `ApplicationWindow`，托盘仍由 Python `QSystemTrayIcon` 管理。
- 目录草案：`ui/main.qml`、`ui/pages/StatusPage.qml`、`ui/pages/VibrationPage.qml`、`ui/components/*`、`ui/icons/*`；Python 侧新增 `app/ui_model.py`（属性/信号/槽）。
- 打包：PyInstaller 收集 QtQuick/QtQml 模块与 QML 文件；QML 资源用 `:/` 或随包目录；`--self-test` 增加 QML 加载检查。
- 首版范围：状态页 + 震动页；设备与系统页在第二阶段迁移；期间隐藏旧扳机/Xbox UI。
- 功能不变：桥接、Sensa、HidHide、音频保护、开机自启的行为不改；只改呈现与交互。

## 6. 阶段

1. 设计稿 + 静态 mockup（状态页、震动页）→ 用户确认。
2. QML 窗口 + Python 上下文 + 两个页面；托盘/窗口生命周期；打包自检。
3. 设备与系统页 QML 化；电平刷新性能与真实桌面 QA。
4. 收尾：文档、版本、安装包。（不在本轮）

当前进度（2026-10-25，1.1.23 候选）：阶段 1、2 已完成；系统页用 QML 实现了开机自启、音频保护、HidHide、日志四项，关于卡片和减少动画开关已移除，设置卡片铺满内容区、四行等分高度。状态页合并为两个 Tab，删除重复输出通道、握把说明小字和输出页脚注释；状态条改为实底并提高字号/对比度；卡片、按钮与 Tab 的绿色悬停动画已移除，电平柱改用暗一档绿色降低大面积高亮。左右握把强度已拆成独立增益，手柄标注显示实时百分比并支持点击选中/高亮；总开关统一门控强度、柔和、测试和标注，关闭时会结束正在进行的握把测试。标题栏文案改为“Wolverine to DS5”，左侧品牌图标换成手柄图形；右下角状态栏、窗口标题和托盘提示统一使用该名称。字体改为 Roboto + 微软雅黑回退链（此前中文实际落到宋体，才显得又细又糊），字号与字重整体加大。安装包尚未重打，真实桌面交互待实测。

## 7. 验收

- 视觉：雷云式深灰平面、绿色标题/控件、点阵背景与手柄标注一致；无玻璃、粒子或旧 Fluent 控件残留。
- 动效：切换、滑杆、电平、状态变化无跳变/截断；减少动画可用。
- 性能：窗口隐藏时停止刷新，CPU 接近 0；游戏运行时桥接不受影响。
- 功能：PC 模式桥接、握把测试、设置持久化、托盘显示/隐藏/退出与旧版一致。
- 范围：界面不出现扳机设置、Xbox 驱动切换或 Xbox 模式入口；检测到 Xbox 模式只提示切回 PC。
