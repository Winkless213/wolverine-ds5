# 开机报 0xc0000098 修复操作单

> 现象：开机蓝屏“你的电脑/设备需要修复”，错误代码 **0xc0000098**，文件 `\BCD`；按 F1 还是回到同一页。
> 原因：引导配置（BCD）损坏或缺失。**系统和个人文件都还在，不需要重装、不需要格式化。**

## 准备

- 一个 8GB 以上 U 盘（会被清空）；
- 一台能上网的电脑；
- 约 15 分钟。

## 第一步：制作启动 U 盘（在另一台电脑上）

1. 浏览器打开微软官网，搜索 **“下载 Windows 11”**，下载 **媒体创建工具（Media Creation Tool）**；
2. 插入 U 盘，运行工具；
3. 选 **“为另一台电脑创建安装介质”** → 版本默认 → 介质选 **U 盘** → 选中你的 U 盘 → 下一步；
4. 等进度条走完（10–30 分钟），提示“你的 U 盘已准备就绪”。

## 第二步：从 U 盘启动

1. U 盘插到故障电脑**主板后置的 USB 口**（别用前面板、别用集线器）；
2. 开机后**连按 F8**（华硕主板；部分型号是 Esc），出现 `Please select boot device:`；
3. 选带 **`UEFI:`** 前缀的 U 盘那一项，回车。

## 第三步：进入命令提示符

1. 看到 Windows 安装界面，**不要点“现在安装”**；
2. 点左下角 **修复计算机**；
3. **疑难解答 → 高级选项 → 命令提示符**。

## 第四步：重建引导（逐条输入，每条回车）

**① 看分区**
```
diskpart
list volume
```
记下两行：
- 一个 **1000GB 左右的 NTFS** 分区（系统盘），看它的盘符，记作 `C`（也可能是 D）；
- 一个 **100–500MB 的 FAT32** 分区（标“系统”，通常没有盘符），记下它的**卷号**（Volume ###）。

**② 给引导分区分配盘符**
```
select volume <上一步记下的 FAT32 卷号>
assign letter=S
exit
```

**③ 确认系统在哪个盘**
```
dir C:\Windows
```
报“找不到文件”就换 D 试：`dir D:\Windows`。哪个能列出来，后面就用那个字母。

**④ 重建引导**（假设系统在 C）
```
bcdboot C:\Windows /s S: /f UEFI
```
必须看到 **“已成功创建启动文件”**。

**⑤ 补写引导记录**
```
bootrec /scanos
bootrec /rebuildbcd
```
（`rebuildbcd` 显示“找到 0 个 Windows 安装”不影响，第 ④ 步已经修好了。）

**⑥ 重启**
```
exit
```
关机 → **拔掉 U 盘** → 正常开机。

## 如果卡住，按这里判断

| 现象 | 处理 |
| --- | --- |
| `list volume` 里**只有 U 盘**，看不到 1TB 硬盘 | 主板开了 Intel VMD/RST：需要加载 RST 驱动，或改用“微PE / 优启通”这类带 NVMe 驱动的 PE 系统 |
| `bcdboot` 报“尝试复制启动文件失败” | 先执行 `chkdsk C: /f`，再重跑 `bcdboot` |
| 还是失败 | 在 WinRE 里执行 `format S: /FS:FAT32` 后重跑 `bcdboot`（EFI 分区里只有引导文件，不动个人数据） |
| 开机顺序不对 | 按 Del 进 BIOS → Boot → 把 `Windows Boot Manager (硬盘)` 调到第一位 |

## 修好之后（重要）

1. **不要再让 360 清理这个软件**：把 `Wolverine DS5` 安装目录（含 `wolverine-capture.exe`）加入 360 **信任区**；
2 360 的“恢复区”里如果有被清掉的项目，先恢复再说；
3. HidHide 如果被删了，可以暂时不装——只影响“对游戏隐藏实体手柄”这一项功能；
4. 雷云（Razer Synapse）需要重装的话，握把震动才会恢复。

## 一句话转述版

> 开机报 0xc0000098，引导配置坏了。用 U 盘进 WinRE，`bcdboot C:\Windows /s S: /f UEFI` 重建引导即可，**不要重装系统、不要格式化、数据要保留**。
