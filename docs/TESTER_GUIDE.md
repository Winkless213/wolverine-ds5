# Wolverine to DS5 · 测试版使用说明

## 这个软件做什么

把雷蛇幻影战狼 V3 Pro（Xbox 手柄）桥接成一个**虚拟 DualSense（PS5 手柄）**，让 PC 游戏把它当成 DualSense 使用；游戏发出的震动经由雷蛇 Sensa 输出到左右握把。

## 使用前准备

- Windows 10 / 11。
- **雷云（Razer Synapse）已安装并在运行**（任务栏有雷蛇图标）。握把震动由它驱动，雷云不在就没有握把震动。
- 雷云里该手柄的震动/触觉功能已打开。
- 手柄用 **USB 线**连接（2.4G 无线也能用，但 USB 更稳）。
- 虚拟手柄依赖 USBip / HidHide，安装包会提示并引导安装。

## 启动顺序（最重要）

1. 先启动 `WolverineDS5.exe`，等主界面显示**“虚拟 DualSense 已挂载”**。
2. 再启动游戏。
3. 如果中途**重启了应用、拔插了手柄、换了 USB 口**：请**退出游戏重新进入**，否则游戏拿不到触觉流，表现为“完全没震动”。

> 记住一句话：**应用在前、游戏在后；应用重开过，游戏也要重开。**

## 界面说明

**状态页**

| 项目 | 说明 |
| --- | --- |
| 已连接 / 停止桥接 | 当前连接状态与桥接开关 |
| 虚拟 DualSense | 虚拟手柄是否已挂载 |
| 雷蛇 Sensa | 握把震动后端是否就绪 |
| 音频保护 | 虚拟设备抢占默认音频时自动切回 |
| HidHide | 是否对游戏隐藏实体手柄 |
| 握把震动 | 总开关、握把强度、柔和握把、震动测试 |
| 实时输出 | 左右握把当前输出强度 |

**系统页**：开机自启、默认音频自动切回、对游戏隐藏实体手柄、日志目录（打开 / 导出）。

## 握把震动设置

- **总开关**：关闭后强度、柔和、测试、实时输出一起失效。
- **握把强度**：0–150%，**左右同时生效**（没有左右独立调节）。0% 等于关闭震动。
- **柔和握把**：默认关闭。打开会压低高频（100Hz 约减半、250Hz 只剩 15%），手感更钝、更弱，一般不建议开。
- **震动测试**：按住手柄 LT / RT 测试，用来确认握把硬件通路正常。

## 触摸板怎么用

实体手柄没有触摸板，虚拟 DualSense 有。映射方式是：

- **按住 View（⧉ 双方块键）+ 推右摇杆** = 手指在触摸板上滑动（摇杆居中 = 触摸板中心，推到底 = 边缘）；
- **轻点 View** = 触摸板点击（手指按下并抬起）；
- 用途举例：蜘蛛侠 2 的“好邻居应用”和拍照模式里的上滑。

## 注意事项与已知问题

1. **刚打开应用时握把要等 10–20 秒**：雷云启动较慢，这期间“震动测试”按钮会显示“等待雷云…”，按下去没有输出是正常现象；等状态条“雷蛇 Sensa”变成“就绪”再测。
2. **旧包不能用来对照**：`dist\WolverineDS5`（1.0.4）里的虚拟手柄组件是修复前版本，表现是“设备管理器里能看到、但游戏识别不到 / 完全没震动”。测试只用当次的候选包。
3. **雷云未运行**时握把不震；应用会尝试自动拉起雷云，失败时不会弹提示，需要手动打开雷云。
4. **柔和握把**默认关闭，打开会明显变弱。
5. **隐藏实体手柄**开启后，游戏才只看到虚拟手柄；如果开关时游戏/Steam 已经开着，需要重启游戏才会生效。
6. **触摸板滑动**目前是“摇杆绝对位置映射”，死区约 24%，方向和灵敏度可能还需要调，欢迎反馈。
7. **单实例**：重复双击只会把已有窗口叫出来，不会开第二个。
8. 退出应用会**自动恢复**被隐藏的实体手柄；异常退出时请重新打开应用再正常退出一次。
9. 手柄换 USB 口后属于新实例，隐藏设置需要重新应用（应用会自动处理，必要时重启应用）。

## 反馈问题时请带上

- **版本号**：界面右下角状态栏（`Wolverine to DS5 · 版本 · 模式`）。
- **游戏与场景**：例如“蜘蛛侠 2，摆荡落地 / 近战 / 拍照模式上滑”。
- **现象**：完全没震动 / 偏弱 / 偏强 / 左右不一致 / 触摸板没反应。
- **当时的设置**：握把强度数值、柔和握把是否开启。
- **日志**：系统页 → 导出日志（生成的文本文件附上）。

## 快速自查

| 现象 | 先查什么 |
| --- | --- |
| 完全没震动 | 雷云是否在跑；是否先开应用后开游戏；应用是否重开过（重开过就重启游戏）；握把强度是否为 0 |
| 软件内测试没反应 | 测试按钮是否显示“等待雷云…”（说明雷云还没识别到握把，等 10–20 秒或手动打开雷云）；状态条“雷蛇 Sensa”是否为“就绪”；雷云里该手柄的震动强度是否为 0 |
| 震动偏弱 | 是否开了柔和握把；握把强度是否较低 |
| 游戏识别不到手柄 | 顺序是否反了（游戏先开）；实体手柄是否仍可见（HidHide 未生效）；重启游戏 |
| 触摸板没反应 | 是否按住 View 且推动右摇杆；该游戏是否支持 DualSense 触摸板 |
| 握把测试也不震 | 雷云没运行或 Sensa 未就绪；换 USB 线/口后重启应用 |
| 状态显示“雷云离线，握把不可用” | 雷云启动时没联网，进了离线模式，不会加载手柄（雷云自己不提示）。恢复网络后重启雷云 |
